Integrated Database Architecture

Full-Stack Zero-Dependency Architecture:

  • SQLite Database: Persistent relational table students and audit_logs via Node.js built-in node:sqlite (zero npm packages required).
  • dataset.csv Integration: The database seeds automatically from dataset.csv, and any new insert, edit, or delete automatically rewrites dataset.csv in real-time.
  • In-Memory Hash Table: 31 prime buckets with Separate Chaining providing $O(1)$ roll number queries.
  • Custom Merge Sort: Stable divide-and-conquer algorithm enforcing multi-tier tie-breakers (Total → Sub1 → Sub2 → RollNo).

College Viva Voce Q&A Guide

Examination Ready

Q1: Why did you choose Separate Chaining over Open Addressing (Linear Probing)?

Answer: Separate chaining handles load factors greater than 1 without clustering breakdown. Deletions in separate chaining are simple linked list unlinks without requiring complex tombstone/dummy markers that degrade open addressing performance.

Q2: Why is the Hash Table capacity chosen as a Prime Number (M = 31)?

Answer: When hash keys have arithmetic patterns (such as sequential roll numbers 101, 102, 103...), choosing a prime table size guarantees that the greatest common divisor between step sizes and the capacity is 1, distributing keys uniformly across all buckets and minimizing clustering.

Q3: Why use Merge Sort for student ranking instead of Quick Sort?

Answer: Merge Sort guarantees $O(n \log n)$ worst-case time complexity, whereas Quick Sort can degrade to $O(n^2)$ if an unbalanced pivot is chosen on sorted academic data. Furthermore, Merge Sort is naturally stable, which preserves deterministic secondary tie-breaking orders.

Q4: How does the application integrate SQLite with dataset.csv?

Answer: On startup, SQLite checks its count and seeds from dataset.csv if empty. On every write operation (Insert, Update, Delete), SQLite executes an atomic SQL transaction and immediately flushes the updated records to dataset.csv, keeping both the relational database and the CSV dataset synchronized.
